# ForgeFlow AI v1.0.0

Target stable university handoff release.

## Highlights

- shared React + FastAPI platform with per-user dashboards, activities, calendar, and timeline
- local student/professor authentication with backend-enforced authorization and CSRF protection
- professor dashboard, GitHub contribution view, project review queue, rubric, and feedback
- typed member-project integration for reviewed Python CLI, static-web, and OpenAPI demos
- generic project detail pages with onboarding gates, health checks, README, demo history, and previews
- immutable student submissions with SHA-256 source snapshots and professor-controlled submission window
- final-delivery preflight requiring integration readiness, frozen submission, professor approval, and approval-after-freeze sequencing
- immutable team release candidates and professor demo handoff flow
- CI, Playwright E2E, dependency audits, CodeQL, CODEOWNERS, and protected main workflow

## Release invariants

`v1.0.0` must only be tagged after all of the following are true in the real local runtime:

1. every tracked member project passes Phase 10 onboarding;
2. every tracked member project has a frozen submission;
3. every latest frozen submission has a professor approval recorded after the freeze;
4. `make delivery-preflight` exits successfully;
5. `make release-package` creates a checksum-verified artifact from clean `main`;
6. the release checklist has been reviewed.

## Artifact contents

The official source artifact is produced with `git archive`, so it contains tracked repository files only. It intentionally excludes runtime SQLite databases, authentication/session state, passwords, API tokens, `.env` files, virtual environments, dependency directories, and local build output.

## Professor quick path

```bash
git clone https://github.com/HoosseinRahimi/ForgeFlow-AI-Core.git
cd ForgeFlow-AI-Core
make demo-handoff
```

Then follow `docs/professor-handoff.md`.

## Release commands

After the final runtime is ready:

```bash
make release-verify
make delivery-preflight
make release-package
make release-tag
```

`make release-tag` creates the annotated tag locally but does not push it automatically. Publish only after reviewing the package and checksum:

```bash
git push origin v1.0.0
```
