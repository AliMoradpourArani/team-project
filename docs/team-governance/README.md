# Team Governance

This directory contains ForgeFlow engineering and operational governance for private Core contributors.

- `developer-access-policy.md`: least-privilege GitHub/system access, branch review, secrets, third-party material, access review and offboarding.
- `legal-onboarding-checklist.md`: operational checklist for signed agreements, pre-existing IP disclosure, access authorization and future incorporation.

## Important boundary

Do **not** store signed agreements, identity records, home addresses, payment records, e-signature audit trails, or other personal legal records in this Git repository. Store those in the approved e-signature/document system.

The legal agreement template is maintained outside the code repository for controlled signing. Repository policies and PR checkboxes support the process but do not substitute for the signed agreement.
